# Reference print-head model (download separately)

`head_geometry.py`, `check_fit.py` and `render.py` read two STEP files from this folder:

- `FullToolhead.step`
- `Frame.step`

They come from "Open source Ender 3 V3 SE Reference Models (.STEP FILES)" by Ally the Sentry on Printables:
https://www.printables.com/model/672045

They are not included in this repo because the model page does not state a license that allows
redistribution. Download them from Printables and put them here to rebuild the CAD parts. The
exported STL, STEP and 3MF files in `../out/` do not need them.
